# ACM template fonts

Fonts required by `@preview/faithful-acmart:0.1.0` for faithful `acmart`
typesetting. Compile the paper from the repository root with:

```sh
typst compile --font-path assets/fonts/acm mirlite-oseair-correctness.typ
```

The font files were obtained from the `fonts/` directory of
[`fzaiser/faithful-acmart`](https://github.com/fzaiser/faithful-acmart) and
are distributed under the SIL Open Font License in `OFL.txt`.
